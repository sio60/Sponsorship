# VERIFYLAB × Creator

Daylist 출시 전 크리에이터 협업 제안 페이지. HTML/CSS/JavaScript 정적 사이트입니다.

## 배포

GitHub Pages에서 main 브랜치의 `/` 경로를 게시합니다.
주소: https://sio60.github.io/Sponsorship/

## 내용 수정

- `index.html`: 제안 문구, 지급일(2026-11-20), 협업비, 테스터 안내
- `app.js`: 메일 수신 주소와 제목/본문, 초대장 인터랙션
- `styles.css`: 흑백 반응형 레이아웃
- `assets/verifylab.png`: 사용자가 제공한 로고 원본
- `assets/daylist-*.png`: 실제 Flutter 개발 화면 (샘플 일정, 광고 비활성화)

첫 화면의 예/아니오는 안내용 인터랙션이며 수락 기록을 전송하거나 저장하지 않습니다. 최종 연락은 사용자가 직접 전송하는 이메일입니다. JavaScript가 꺼져 있어도 제안 내용과 이메일 링크를 볼 수 있습니다.

정식 출시/테스터 초대 링크는 아직 공개하지 않습니다. 실제 설치 방법과 조건은 메일로 별도 안내합니다. 개인정보 폼, 분석 추적, API 키, 계좌 정보는 포함하지 않습니다.
